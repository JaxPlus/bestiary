# MyBestiary App

Aplikacja desktopowa stworzona przy pomocy **Electron** i **Vue.js**.

## Instalacja

1. Sklonuj repozytorium:
   ```bash
   git clone https://github.com/JaxPlus/bestiary
   ```

2. Przejdź do katalogu projektu:
   ```bash
   cd bestiary
   ```

3. Zainstaluj wymagane zależności:
   ```bash
   npm install
   ```

4. Stworzenie builda programu (program będzie się znajdował w folderze out):
   ```bash
   npm make
   ```

## Uruchomienie

Aby uruchomić aplikację w trybie deweloperskim:

```bash
npm start
```
